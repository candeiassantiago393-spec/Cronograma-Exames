# Cronograma Exames

Calendário de estudo (estilo agenda) para **Física e Química A**, **Matemática A** e **Português** — Outubro 2026 → Maio 2027.

**Abrir online:** https://candeiassantiago393-spec.github.io/Cronograma-Exames/

## Funcionalidades

- Vista **mês** e **semana** (no telemóvel abre em semana)
- Filtro **Estudos / Pessoal / Ambos**
- Tarefas pessoais (beleza, trabalho, treinos, eventos) no calendário + tab Pessoal
- Chips por disciplina + filtro na legenda
- Painel lateral, arrastar, reordenar, dificuldade
- Caderno de Erros, Simulacros, Exames IAVE
- Backup / restaurar JSON
- Exportar grelha em **PNG**
- Plano: preparação 1–4 out + 32 semanas a partir de **5 de outubro de 2026**
