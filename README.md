# Cronograma Exames

Calendário de estudo (estilo agenda) para **Física e Química A**, **Matemática A** e **Português** — Outubro 2026 → Maio 2027.

## Funcionalidades

- Vista **mês** e **semana**
- Chips por disciplina + **filtro** (clica na legenda)
- Painel lateral com detalhes, progresso do dia e tipos de tarefa
- Marcar como feitas (guardado no browser)
- Editar / adicionar / apagar tarefas
- **Arrastar** chips ou cartões entre dias
- **Caderno de Erros** (registo a partir de uma tarefa + reforço no calendário)
- **Notas de simulacros** (S1 / S2 / Final) com tabela comparativa
- **Exames IAVE** com links e checkbox “já resolvi”
- Exportar grelha em **PNG**
- Plano: preparação 1–4 out + 32 semanas a partir de **5 de outubro de 2026**

## Abrir localmente

Abre `index.html` no browser, ou serve a pasta:

```bash
# exemplo
npx serve .
```

## GitHub Pages

1. No repositório: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / pasta `/` (root)
4. Guarda e espera 1–2 minutos
5. URL típica: `https://candeiassantiago393-spec.github.io/Cronograma-Exames/`

O progresso (tarefas feitas e edições) fica no `localStorage` do teu browser — não sincroniza entre dispositivos.

## Repor o plano

No calendário, usa **Repor plano original** na legenda (apaga edições e marcas de concluído nesse browser).
