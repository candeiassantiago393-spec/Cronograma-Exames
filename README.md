# Cronograma Exames

Calendário de estudo (estilo agenda) para **Física e Química A**, **Matemática A** e **Português** — Outubro 2026 → Maio 2027.

## Funcionalidades

- Vista mensal com chips por disciplina
- Painel lateral ao clicar num dia (detalhes, tipo de tarefa, duração)
- Marcar tarefas como feitas (guardado no browser)
- Editar / adicionar / apagar / mover tarefas (alterando a data)
- Exportar a grelha do mês em **PNG**
- Plano completo: preparação 1–4 out + 32 semanas a partir de **5 de outubro de 2026**

## Abrir localmente

Abre `index.html` no browser, ou serve a pasta:

```bash
# exemplo
npx serve .
```

## GitHub Pages

1. No repositório: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / pasta `/` (root)
4. Guarda e espera 1–2 minutos
5. URL típica: `https://candeiassantiago393-spec.github.io/Cronograma-Exames/`

O progresso (tarefas feitas e edições) fica no `localStorage` do teu browser — não sincroniza entre dispositivos.

## Repor o plano

No calendário, usa **Repor plano original** na legenda (apaga edições e marcas de concluído nesse browser).
